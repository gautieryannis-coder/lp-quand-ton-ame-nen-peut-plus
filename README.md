- `politique-confidentialite.html` — Politique de confidentialité (RGPD)

## 🚀 Déploiement

Cette landing page est hébergée via **GitHub Pages** :

1. Settings → Pages
2. Source : `Deploy from a branch`
3. Branch : `main` / `root`
4. Save

URL publique : `https://gautieryannis-coder.github.io/lp-quand-ton-ame-nen-peut-plus/`
